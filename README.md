# GeneDoc

Type a human gene and download its reference sequence as a checked Word file.

**Open it:** https://clairevaltin.github.io/GeneDoc/

## What it does

- Fetches the **MANE Select** transcript of any human gene live from NCBI (Datasets and E-utilities)
- Builds the **genomic sequence** with the flank size you choose: exons in uppercase, alternating colours so each new exon stands out; introns and flanks in lowercase
- Builds the **coding sequence (CDS)**
- Draws the **gene structure**; click an exon to find it in the sequence
- Runs **consistency checks** on the rebuilt sequences
- Exports everything as a **Word (.docx)** file, or lets you copy each sequence
- Works with **GRCh38** or **T2T-CHM13**

Handy for preparing Sanger sequencing references and primer design. Only the gene symbol is sent to NCBI.

## How to use

Open the link above, type a gene symbol and press **Get sequences**. Nothing to install.
